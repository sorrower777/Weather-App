# Weather App

A simple, responsive web application that provides current weather information and a multi-day forecast for any location worldwide. This project leverages external weather APIs to deliver up-to-date and accurate weather data.

## Features

- **City Weather Search:** Quickly search for current weather by entering a city name.
- **Automatic Geolocation:** Detects and displays your local weather based on your current location.
- **Detailed Weather Data:** Shows temperature, humidity, wind speed, and weather conditions.
- **Multi-Day Forecast:** View a forecast for the coming days.
